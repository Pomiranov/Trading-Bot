# RSI (Relative Strength Index)

## Что это
Осциллятор импульса (0–100), разработанный Дж. Уэллсом Уайлдером. Измеряет
скорость и величину последних изменений цены. НЕ самостоятельный сигнал на
покупку/продажу — фильтр и инструмент оценки состояния рынка.

## Как рассчитывается
RSI = 100 − 100 / (1 + RS), где RS = Average Gain / Average Loss за N периодов.
Стандартный период N = 14.

## Что показывает
- RSI > 70 — возможная перекупленность; RSI > 80 — очень сильный восходящий
  импульс. Высокий RSI НЕ означает обязательный разворот вниз.
- RSI < 30 — возможная перепроданность; RSI < 20 — очень сильный нисходящий
  импульс. Низкий RSI НЕ означает обязательный разворот вверх.
- Центральная линия 50: RSI > 50 — бычий импульс, RSI < 50 — медвежий.
  В трендовых стратегиях пересечение 50 значимее, чем достижение 70/30.
- Дивергенции: медвежья (цена обновила максимум, RSI — нет) — ослабление роста;
  бычья (цена обновила минимум, RSI сформировал более высокий минимум) —
  ослабление падения. Требуют подтверждения, не сигнал на немедленный вход.

## Как использовать
- **ranging**: классические уровни 70/30 работают лучше всего; покупка ~30,
  продажа ~70, с подтверждением уровнями поддержки/сопротивления
- **trending**: RSI долго остаётся в экстремальных зонах. Восходящий тренд —
  диапазон 40–80, откаты к 40–50 — поиск входа по тренду. Нисходящий — 20–60,
  подъёмы к 50–60 — вход по тренду. Развороты только по 70/30 в сильном
  тренде — не использовать
- **volatile**: более широкие уровни 80/20, обязательное подтверждение другими
  индикаторами
- Сочетания: ADX + RSI (сила тренда + момент отката), EMA + RSI (входы по
  тренду), уровни + RSI (разворотные зоны), Price Action + RSI (фильтрация)
- Типичные ошибки: продавать только из-за RSI > 70; покупать только из-за
  RSI < 30; игнорировать рыночный режим; торговать по RSI без подтверждения

## Параметры
- Период: 14 (стандарт); быстрый 7, медленный 21
- Пороги: 70/30 классика; 80/20 при высокой волатильности
- Трендовые диапазоны: 40–80 (uptrend), 20–60 (downtrend)
