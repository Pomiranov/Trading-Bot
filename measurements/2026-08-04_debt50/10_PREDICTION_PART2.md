## ЧАСТЬ 0 — РЕШЕНО ДО КОДА: секция `indicators:` для замера НЕ ТРЕБУЕТСЯ

Три факта, каждый замерен:

1. **Механизм передачи уже работает.** `engine.py:150-155` строит
   `IndicatorEngine(**{**indicator_params, **divergence_params, …})`, то есть секция
   `indicators:` из файла правил дошла бы до движка **без единой правки кода**. Её
   просто нет в `rules_osc_range.yaml`.
2. **Замер идёт на КОПИИ правил** (так делались все прогоны 03.08). Копия для плеча
   H4 может нести секцию с пересчитанными значениями; боевому файлу для этого меняться
   не нужно.
3. **Цена добавления в боевой файл — сдвиг отпечатка при нулевом изменении
   поведения.** `RulesEngine.rules_version` хеширует, дословно, «ВЕСЬ разобранный
   yaml, а не выборку секций». Значит секция с теми же значениями, что в коде,
   поведение не меняет **ни на копейку**, а `rules_version` **сдвигает** — новые
   сделки форварда получат новый отпечаток, и привязку опорных троек к переходу
   пришлось бы делать явно.

⇒ **Секция в этот заход НЕ добавляется.** Часть 2в не выполняется — **по решению, а не
по недосмотру**. Выносится отдельным предметом с ценой: сдвиг `rules_version` +
явная привязка троек к переходу. Бандлить сдвиг отпечатка в подготовку замера нельзя.
