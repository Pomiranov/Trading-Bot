# Пробой уровня с подтверждением объёмом (Volume Confirmed Breakout)

## Тип

Вход (Entry Strategy)

## Категория

Трендовая стратегия пробоя.

## Рынки

- stocks
- futures

## Рыночный режим

Стратегия применяется **только** в режиме **Trending**.

### Требования к режиму

- Market Regime = Trending
- Направление тренда соответствует направлению сделки
- ADX(14) ≥ 25
- Цена находится по соответствующую сторону EMA50
- EMA50 имеет наклон в сторону сделки

Стратегия не применяется в режимах:

- Ranging
- Volatile (если волатильность превышает допустимый уровень риска)

---

# Индикаторы

Используются следующие индикаторы:

- EMA(50)
- ADX(14)
- ATR(14)
- RSI(14)
- Volume SMA(20)

---

# Определения

## Уровень сопротивления

Уровнем сопротивления считается локальный максимум, который:

- тестировался не менее двух раз;
- не был закрыт выше до текущего пробоя;
- сформирован за последние **N** свечей (параметр стратегии).

## Тест уровня

Тестом считается касание уровня, при котором:

```text
|High − Resistance| ≤ 0.2 × ATR(14)
```

Значение допуска является параметром стратегии.

## Volume Ratio

Отношение текущего объёма к среднему объёму:

```text
VolumeRatio =
CurrentVolume /
SMA(Volume, 20)
```

---

# Условия входа (Long)

Все условия должны выполняться одновременно.

### 1. Пробой уровня

Свеча закрывается выше сопротивления:

```text
Close >
Resistance +
0.1 × ATR(14)
```

Буфер позволяет исключить ложные пробои.

---

### 2. Подтверждение объёмом

```text
VolumeRatio ≥ 1.5
```

---

### 3. Подтверждение тренда

```text
ADX(14) ≥ 25
```

и

```text
Close > EMA50
```

и

```text
EMA50 Slope > 0
```

---

### 4. Подтверждение импульса

```text
50 ≤ RSI(14) ≤ 75
```

Если RSI выше верхней границы, сигнал считается перегретым и пропускается.

---

# Условия входа (Short)

Аналогичны Long, но зеркально.

```text
Close <
Support − 0.1 × ATR
```

```text
VolumeRatio ≥ 1.5
```

```text
ADX ≥ 25
```

```text
Close < EMA50
```

```text
EMA50 Slope < 0
```

```text
25 ≤ RSI ≤ 50
```

---

# Стоп-лосс

Для Long:

```text
Stop =
Resistance − 0.5 × ATR(14)
```

Для Short:

```text
Stop =
Support + 0.5 × ATR(14)
```

Стоп определяется **до открытия позиции**.

---

# Размер позиции

Размер позиции рассчитывается по правилам Position Sizing.

```text
RiskAmount =
Capital × Risk%
```

```text
PositionSize =
RiskAmount /
RiskPerUnit
```

Рекомендуемый риск:

- 0.5–1.5% капитала

Максимально допустимый риск:

- 2%

---

# Выход из сделки

## Тейк-профит

```text
TakeProfit = Entry + 2R
```

или

```text
Reward : Risk = 2 : 1
```

---

## Перевод в безубыток

После достижения прибыли:

```text
+1R
```

стоп переносится в цену входа.

---

## Дополнительный выход

Позиция закрывается досрочно, если:

- цена закрылась обратно за уровень пробоя;
- сформировался противоположный сигнал;
- рынок перестал соответствовать режиму Trending.

---

# Отмена сигнала

Сигнал считается недействительным, если:

- пробой произошёл без повышенного объёма;
- свеча закрылась обратно под уровень (для Long) или выше уровня (для Short);
- после пробоя отсутствует продолжение движения в течение **3** свечей;
- изменился рыночный режим.

---

# Ограничения

Не открывать сделку:

- в первый час торгов;
- перед закрытием основной торговой сессии;
- перед публикацией важных макроэкономических новостей;
- при экстремально высокой волатильности;
- если спред значительно превышает средний;
- если невозможно определить корректный стоп-лосс.

---

# Параметры стратегии

| Параметр | Значение |
|----------|----------|
| EMA Period | 50 |
| ADX Period | 14 |
| ATR Period | 14 |
| RSI Period | 14 |
| Volume SMA | 20 |
| Volume Ratio | ≥ 1.5 |
| ADX Threshold | ≥ 25 |
| RSI Long | 50–75 |
| RSI Short | 25–50 |
| Stop Buffer | 0.5 ATR |
| Breakout Buffer | 0.1 ATR |
| Reward/Risk | 2 : 1 |
| Break Even | +1R |

---

# Использование в QuantFlow

Последовательность работы стратегии:

```text
Определение Market Regime
            ↓
Поиск уровня
            ↓
Проверка пробоя
            ↓
Проверка объёма
            ↓
Подтверждение тренда
            ↓
Расчёт Stop Loss
            ↓
Расчёт размера позиции
            ↓
Проверка ограничений риска
            ↓
Отправка заявки
```

# Источник

Документ описывает эталонную реализацию стратегии **Volume Confirmed Breakout** для QuantFlow.

Стратегия соответствует `strategy_id = breakout_moex` в `belief_system` и предназначена для автоматического исполнения в режиме **Trending**.
