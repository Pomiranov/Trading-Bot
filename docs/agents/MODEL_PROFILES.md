## Три вещи, о которые легко споткнуться

**`opus[1m]` — не Opus 5.** На установленной версии это Opus 4.8 с 1M контекста. Настоящий Opus 5 — это `claude-opus-5[1m]` (или `claude-opus-5` для 200k). ACP-сервер `claude-agent-acp 0.44.0` не показывает Opus 5 в своём списке моделей, но принимает его: модель вне curated-списка разрешена, и это подтверждено рабочим тестом. Обновление образа для Opus 5 **не требуется**.

**Имя профиля ограничено** шаблоном `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$` — пробелы и тире «—» API отвергает. Отсюда дефисная форма имён.

**`acp_command` во всех профилях пуст** — так и надо. SDK сам подменяет `npx -y <pkg>` на вложенный в образ бинарник (`claude-agent-acp`, `codex-acp`, `gemini --acp`), поэтому запуск агента не требует сети.

## Правило выбора

Название профиля всегда отражает реальную модель. Если модель в профиле меняется — переименовывается и профиль. Профиль с именем, обещающим одну модель, а работающий на другой, считается дефектом среды.
