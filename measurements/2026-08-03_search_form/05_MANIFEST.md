## Итог по частям

### Часть 1 — отказ МОЛЧАЛИВЫЙ, класс правила 12

stderr 0 байт, перенаправления в записанной форме нет. Код возврата совпадает с

### Часть 2 — область задана ПРЕДИКАТОМ

`git cat-file --batch-all-objects` вместо перечня ссылок. Форма:

- покрывает всю базу объектов: упакованные и россыпью, достижимые и
  недостижимые, висячие и живые только через reflog;
- ревизии после `--` не ставит вовсе — конструкции нет;
- при собственной поломке завершается кодом **3**, а не тихим нулём. Проверено
  двумя отказами: пустое `QF_NEEDLE` → 3, каталог не репозиторий → 3;
- печатает **число просмотренных объектов**. Ноль просмотренных при нулевом
  результате даёт код 3, а не 0 — различает сама форма.

Коды: `0` просмотр состоялся, совпадений нет; `1` совпадения есть; `3` отказ формы.

**Оба рабочих дерева делят ОДНУ базу объектов** — `git rev-parse --git-common-dir`
во втором дереве даёт `D:/Trading-Bot-Nik/.git`, число объектов в обоих 2194.
Следствие: один прогон по базе покрывает закоммиченную историю обоих деревьев;
раздельно проверять нужно только **незакоммиченные** файлы рабочих деревьев.

### Часть 3 — ПОДСАДКА. Форма принимается по числу, не по описанию

Временный репозиторий `mktemp -d` вне рабочего дерева, метка `QF_CANARY_7f3a91`
(метка, не токен), `gc.auto 0` чтобы висячий объект не выкосило.

Состояния подтверждены **до** прогона форм, проверкой по БЛОБУ (не по коммиту:
`git rev-list --all` перечисляет только коммиты, блоба в нём нет никогда — область
для блоба задаётся `--objects`):

| случай | в `--all` | в `--all --reflog` | в базе объектов |
|---|---|---|---|
| С1 достижимый коммит | ДА | ДА | ДА |
| С2 снят `--amend`, reflog истёк | **НЕТ** | **НЕТ** | ДА |
| С3 коммит удалённой ветки | НЕТ | ДА | ДА |

`git fsck --unreachable` показывает блоб С2 дословно.

| форма | С1 | С2 | С3 | итог |
|---|---|---|---|---|
| **0.** сломанная, ревизии после `--` | нет | нет | нет | **0 из 3, молча** |
| **1.** `git grep … $(git rev-list --all)` | ДА | нет | нет | 1 из 3 |
| **2.** то же с `--all --reflog` | ДА | **нет** | ДА | 2 из 3 |
| **3.** предикат по базе объектов | ДА | **ДА** | ДА | **3 из 3** |

Отрицательный контроль: метка, которой нет → просмотр состоялся, совпадений 0,
код 0.

🚩 **Находка сверх задания.** Форма 2 — это форма 3 из `0e9e078`, **написанная
правильно**. Она С2 всё равно не находит. Значит исходный замысел был недостаточен
**не только исполнением, но и областью**: починка `--` дала бы 2 из 3 и снова
прочиталась бы как «чисто».

### Три дефекта первой версии подсадки — исправлены, а не истолкованы

1. С2 не подсаживался: `git commit --amend` отказывал («стал бы пустым»), потому
   что в коммите не было ничего кроме снимаемого файла. Добавлен второй файл;
2. три случая сворачивались в ОДИН блоб: содержимое файлов было одинаковым, а git
   дедуплицирует по содержимому. У каждого случая своя строка;
3. python печатал в cp1251, вывод был нечитаем. `PYTHONUTF8=1`.

Первая версия дала бы «форма нашла 1 из 3» и выглядела бы как недостаточность
формы, хотя недостаточной была ПОДСАДКА.

предсказания. Форма нашла её и атрибутировала — блоб
`1ef1af1f704421bfe35f583d68b56af426b37e5d`, путь
`measurements/2026-08-03_search_form/00_PREDICTION.md`, коммит `fbe60645`.

Ценность выше, чем у задуманного контроля: **правило 12 выполнено и на боевом
репозитории**, а не только на временном.
