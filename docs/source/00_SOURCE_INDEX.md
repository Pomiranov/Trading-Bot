## 1. Что за проект

**Quant** (в коде — QuantFlow) — автоматический торговый оператор для Московской биржи. Читает свечи MOEX, оценивает их по 25 заранее записанным правилам, измеряет накопленную «уверенность» в стратегии по закрытым сделкам, проверяет риск-лимиты **до** обращения к брокеру и исполняет заявку через Т-Инвестиции. Два интерфейса — веб-Dashboard и Telegram-бот — читают одно состояние из общей TimescaleDB. Отдельно существует маркетинговый сайт на Next.js.

**Позиционирование:** проверяемость решения вместо обещаний доходности. На сайте нет ни одной цифры результата — и это построенная позиция, подтверждённая кодом.

**Три вещи, которые нужно знать сразу:**
1. **Система однопользовательская, а сайт продаёт подписки.** Клиентских аккаунтов, подписок и платежей в коде нет вовсе.
2. **Автономный цикл торгует без подтверждения человека**, хотя сайт обещает «Каждую сделку можно подтверждать вручную». Реализация подтверждения существует, но заперта в неиспользуемом legacy-модуле.
3. **`CLAUDE.md` и `README.md` содержат утверждения, противоречащие коду** — включая неверный корень проекта. Не используйте их как источник истины.

- **Production-среда** — недоступна: TLS, реверс-прокси, права ОС, Windows Server 2019.
- **Реальные Core Web Vitals** — dev-сервер непоказателен.
- **Кросс-браузерность** (Safari/Firefox/iOS) — доступен только Chromium; штатный скрипт `qa:landing:webkit` не работает ([Q-03](08_QA_TESTING_PERFORMANCE_AND_RELIABILITY_AUDIT.md)).

- **Нагрузка, конкурентные операции, penetration-тестирование** — не входили в задачу.
