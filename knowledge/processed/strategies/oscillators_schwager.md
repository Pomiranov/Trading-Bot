# Осцилляторы для боковика (Oscillator Divergence + Confirmation, по Швагеру/Бировицу)

## Тип
Вход (контртрендовый, для диапазона) + управление позицией

## Рынки
stocks, futures

## Рыночный режим
**ranging** — но режим НЕ определяется через ADX-фильтр (урок вырожденной
конфигурации trend_moex). Ключевая идея главы: **не угадывать режим, а
требовать ценового подтверждения осцилляторного сигнала**. Автор (Бировиц)
прямо пишет: попытки подобрать индикатор под режим обречены — «каждая
тенденция завершается диапазоном, каждый диапазон пробивается трендом».
Осциллятор + подтверждение ценой самоотбирает подходящие моменты.

⚠️ Продавать перекупленность / покупать перепроданность «в лоб» хорошо
работает в диапазоне и «приведёт к катастрофе» в тренде — поэтому голые
пороги RSI/стохастика сигналом НЕ являются, только расхождение + подтверждение.

## Главные осцилляторы (выбор Бировица)

Следит за тремя: **MACD, RSI, стохастик** («рисуют похожую, но не совпадающую
картину»). Параметры фиксированные для всех рынков, без пооптимизационной подгонки:

| Осциллятор | Параметры | Зоны OB/OS | Примечание |
|---|---|---|---|
| MACD | 12-26-9 (EMA12−EMA26; сигнальная = EMA9 линии MACD) | нет фикс. границ → автокалибровка | гистограмму MACD считает слишком чувствительной |
| RSI | **9 дней** (не 14 Уайлдера) | **70 / 30** | лучший осциллятор для совмещения с уровнями и линиями тренда |
| Стохастик | **медленный, 14 дней** (%K = сглаженный быстрый %D; %D = SMA3 от него) | **70 / 30** | сигнал: %K пересекает %D + выход из зоны |

Вспомогательные (та же интерпретация): осциллятор ДСС = EMA5 − EMA20;
momentum M = C − C(n); ROC = C / C(n), n = 9.

## Автокалибровка зон перекупленности/перепроданности

Для осцилляторов без фиксированных границ (ДСС, momentum, ROC, MACD):
провести горизонтальные линии через самые высокие пики и самые глубокие
впадины осциллятора так, чтобы **в крайних зонах осциллятор находился
только ~10% всего времени** (90% значений — между линиями).

Измеримая реализация: на скользящем окне истории осциллятора (например,
500 баров) OB = 95-й перцентиль значений, OS = 5-й перцентиль
(по ~5% времени с каждой стороны, вместе ~10%). Пороги автоматически
адаптируются под инструмент и волатильность — не нужны «магические числа»
под каждый тикер.

## Расхождение (divergence) — формальные определения

Подробно, с точными книжными формулировками и маппингом на реализацию:
[[oscillator_divergence]] (processed/technical/).

- **Бычье**: цена делает более низкий минимум (LL), осциллятор на этом же
  движении делает более высокий минимум (HL).
- **Медвежье**: цена делает более высокий максимум (HH), осциллятор —
  более низкий максимум (LH).

⚠️ Расхождения часто ложные (при сильном тренде их бывает 2–3+ подряд до
разворота) → само по себе расхождение НЕ сигнал. Обязательно ценовое
подтверждение: пробой КСС (лучший метод), пробой линии тренда, день
разворота, микро-M/W.

## Правило «2 из 3»

Ждать расхождения **минимум на двух из трёх** осцилляторов (MACD, RSI,
стохастик) → «более высокий процент выигрышных сделок». Одиночное
расхождение игнорируется.

Дополнение для стохастика: после медвежьего расхождения ждать пересечения
%K ниже %D с уходом %K под 70; после бычьего — пересечения %K выше %D
с подъёмом %K над 30.

## Система 1: расхождение + коридор скользящих средних (КСС)

КСС = канал между EMA(High, 28) и EMA(Low, 28). Границы работают как S/R;
ширина канала = мера волатильности.

Long:
1. Бычье расхождение (лучше на ≥2 осцилляторах)
2. Buy-stop на 1 тик выше EMA28 максимумов; переставлять каждый бар,
   пока не исполнится
3. Отмена ожидания: цена И осциллятор сделали новые минимумы до пробоя
   верхней границы → ждать следующего расхождения
4. Стоп после входа: 1 тик ниже EMA28 минимумов (риск ≈ среднедневной
   диапазон + несколько тиков)
5. Ведение: trailing по нижней границе КСС до исполнения
6. **Stop-and-reverse**: если пробою нижней границы предшествовало
   медвежье расхождение — закрыть long И открыть short одновременно

Short — зеркально (sell-stop под EMA28 минимумов, стоп над EMA28 максимумов).

## Система 2: микро-M вершины / микро-W впадины

Полностью формализованный паттерн входа (подтверждение расхождения).

Впадина микро-W (long):
1. Новый минимум цены + бычье расхождение с осциллятором
2. Ждать бар с закрытием ВЫШЕ предыдущего закрытия, сразу за которым —
   бар с закрытием НИЖЕ (пара «вверх/вниз», строго подряд)
3. Вход: buy-stop на 1 тик выше максимума этой пары баров
   (день входа может быть не сразу после пары)
4. Стоп: 1 тик ниже минимума расхождения (минимум цены в точке 1)
5. Выход: цель по прибыли ИЛИ следящая остановка

Вершина микро-M (short) — зеркально: новый максимум + медвежье
расхождение → пара «вниз/вверх» → sell-stop на 1 тик ниже минимума пары →
стоп на 1 тик выше максимума расхождения.

## Управление позицией и цели (советы Бировица)

- Первоначальный риск R = |вход − стоп| — известен ДО входа
- После движения в прибыль на ≥1R — стоп в безубыток
- **Цель: 2–3R** (на волатильных рынках фиксация у цели надёжнее удержания
  до разворота тренда)
- При нескольких контрактах: часть закрыть на 2R, остаток вести
  следящей остановкой
- Держать до разворота (trailing по КСС) — только при устойчивом тренде

## Отмена сигнала
- КСС-ожидание: новые минимумы цены и осциллятора до пробоя верхней
  границы → сетап отменён
- Микро-W: срабатывание стопа под минимумом расхождения
- Противоположное расхождение + пробой противоположной границы КСС →
  stop-and-reverse

## Риск
- Размер позиции: по правилам Position Sizing (RiskAmount = Capital × Risk%)
- Риск 0.5–1.5%, максимум 2% (железный лимит)
- Риск в КСС-системе структурно мал (ширина канала ≈ дневной диапазон)

## Параметры
| Параметр | Значение (книга, дни) | Адаптация H1 |
|----------|----------------------|--------------|
| MACD | 12-26-9 | 12-26-9 (в барах) |
| RSI | 9, зоны 70/30 | 9 |
| Стохастик | 14 медленный, зоны 70/30, %D=3 | 14-3-3 |
| КСС | EMA(High,28) / EMA(Low,28) | 28 |
| Автокалибровка OB/OS | ~10% времени в зонах | перцентили 95/5, окно 500 баров |
| Кворум расхождений | ≥2 из 3 (MACD, RSI, стохастик) | то же |
| Окно поиска расхождения | «недавние» экстремумы | ≤70 баров между экстремумами |
| Вход | 1 тик за границей (КСС / пары баров) | 1 шаг цены (+0.05×ATR буфер) |
| Безубыток | +1R | то же |
| Цель | 2–3R | 2R |

## Заметки
- Комплементарна trend_moex: работает именно там, где трендовая стратегия
  теряет. Вместе с range_trap_moex (гл. 11) закрывает боковик с двух сторон.
- ⚠️ Текущий фильтр rules.yaml `weak_trend_block` (BLOCK при ADX < 20)
  блокирует торговлю ровно в том режиме, где эта стратегия зарабатывает.
  При внедрении фильтр нужно снять для осцилляторных правил (фильтры
  в движке глобальные → потребуется механизм скоупинга фильтров на
  стратегию или отдельный RulesEngine-инстанс для этой стратегии).
- Не реализовано в IndicatorEngine: стохастик (%K/%D), RSI(9) (есть только 14),
  КСС (EMA максимумов/минимумов), детектор расхождений, трекер микро-M/W.
- Предлагаемый strategy_id: `osc_range_moex` (добавить в belief_system).
- Из заключения главы: «нельзя позволять осцилляторам затмевать игру самих
  рыночных цен» — приоритет ценового подтверждения над показаниями индикатора.
