## Handoff contract

- реализация, рефакторинг, багфикс, миграции, безопасность, PR → чат **02 Engineering**;
- интерфейс, дизайн-система, визуальная приёмка, Stitch → чат **03 UI/UX**;
- позиционирование, воронка, SEO, контент, тарифы → чат **04 Marketing**;
- мандат на T0, merge, деньги, юридический текст, секреты → **владелец** (OWNER CHECKPOINT).

Передача в Engineering обязана содержать: Task ID, зону T0–T4 и радиус, ветку по правилам
`AGENTS.md §3`, файлы для чтения перед правкой, что можно и нельзя трогать конкретными
путями, Definition of Done командами с ожидаемым выводом, раздел «Не делать», для T0/T1 —
падающий тест до правки и «Откат», требование отчёта с выводом каждого гейта.
Приём результата — по 17 полям `docs/agents/HANDOFF.md`; неполный handoff = задача не сдана.
