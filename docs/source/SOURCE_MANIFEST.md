## Как этим пользоваться

1. Роль не читает пакет целиком. Роль открывает
   [`docs/agents/QUANT_CONTEXT_INDEX.md`](../agents/QUANT_CONTEXT_INDEX.md),
   находит нужный вопрос и идёт в один документ.
2. Любое число, путь, endpoint, имя таблицы или значение токена из пакета
   перепроверяется по коду перед использованием в решении. Приоритет источников —
   `AGENTS.md §2`: код → Source Pack → всё остальное.
3. Столбец «Противоречия» — это уже найденные расхождения. Их не нужно искать заново;
   их нужно учитывать.
4. Значимое изменение обязывает обновить пакет (`docs/source/00 §8`) и этот манифест.
