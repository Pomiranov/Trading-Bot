# Пробой уровня с подтверждением объёмом (Volume Confirmed Breakout)

## Тип
Вход

## Рынки
stocks, futures

## Рыночный режим
Только **trending**. Требования: ADX(14) ≥ 25, цена по соответствующую сторону
EMA50, наклон EMA50 в сторону сделки, направление тренда совпадает с направлением
сделки. Не применяется в ranging и volatile.

## Определения
- **Уровень сопротивления** — локальный максимум, тестировавшийся ≥ 2 раз,
  не закрытый выше до текущего пробоя, сформирован за последние N свечей.
- **Тест уровня** — касание с допуском |High − Resistance| ≤ 0.2 × ATR(14).
- **VolumeRatio** = CurrentVolume / SMA(Volume, 20).

## Условия входа
Long (все одновременно):
- Пробой: Close > Resistance + 0.1 × ATR(14) — буфер отсекает ложные пробои
- Объём: VolumeRatio ≥ 1.5
- Тренд: ADX(14) ≥ 25 И Close > EMA50 И наклон EMA50 > 0
- Импульс: 50 ≤ RSI(14) ≤ 75 (выше 75 — сигнал перегрет, пропуск)

Short — зеркально:
- Close < Support − 0.1 × ATR(14)
- VolumeRatio ≥ 1.5
- ADX ≥ 25 И Close < EMA50 И наклон EMA50 < 0
- 25 ≤ RSI ≤ 50

## Условия выхода
- Тейк-профит: 2R (Reward:Risk = 2:1)
- Стоп-лосс: Long — Resistance − 0.5 × ATR(14); Short — Support + 0.5 × ATR(14).
  Определяется ДО открытия позиции.
- Трейлинг: после +1R стоп переносится в безубыток (цену входа)
- Досрочный выход: цена закрылась обратно за уровень пробоя; противоположный
  сигнал; рынок перестал соответствовать режиму trending

## Отмена сигнала
- пробой без повышенного объёма
- свеча закрылась обратно за уровень
- нет продолжения движения в течение 3 свечей после пробоя
- изменился рыночный режим

## Риск
- Размер позиции: по правилам Position Sizing (RiskAmount = Capital × Risk%)
- Рекомендуемый риск: 0.5–1.5% капитала
- Максимальный риск на сделку: 2% (железный лимит)

## Параметры
| Параметр | Значение |
|----------|----------|
| EMA Period | 50 |
| ADX / ATR / RSI Period | 14 |
| Volume SMA | 20 |
| Volume Ratio | ≥ 1.5 |
| ADX Threshold | ≥ 25 |
| RSI Long / Short | 50–75 / 25–50 |
| Breakout Buffer | 0.1 ATR |
| Stop Buffer | 0.5 ATR |
| Reward/Risk | 2:1 |
| Break Even | +1R |

## Заметки
Не открывать сделку: в первый час торгов; перед закрытием основной сессии;
перед важными макро-новостями; при экстремальной волатильности; если спред
значительно выше среднего; если невозможно определить корректный стоп-лосс.
Порядок работы: режим → уровень → пробой → объём → тренд → стоп → размер
позиции → проверка лимитов риска → заявка.
