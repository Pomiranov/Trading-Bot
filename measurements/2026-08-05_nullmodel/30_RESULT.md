# Часть D: нуль-модель. Результат серии

Сид **20260805**, `N = 200`, годных прогонов **200 из 200** (все с `n = 18`, недобора
нет). Пул — только OOS, **3 462** бара. Наблюдённых входов D1/OOS: **18** (сошлось).

## 1. 🚩 КОНТРОЛЬ ДРЕЙФА ПРОВАЛЕН КАК НАПИСАН. Причина замерена

Оба контроля — до и после серии — дали **одинаково**:

```
n=18  WR=72.2%  PF=1.638  PnL=127747.96
цель: n=18  WR=72.2%  PF=1.638  PnL=127747.97
```

Три величины из четырёх совпали **точно**. Разошёлся `PnL` — на **`0.01`**, то есть на
`8·10⁻⁸` относительной величины.

**Причина измерена, а не предположена:** CSV хранит `round(t.pnl, 2)` **по каждой
сделке** (`run_osc_oos_debug.py`), а сумма округлённых **не равна** округлению суммы.
Замер: сумма 18 округлённых значений из замороженного файла = **`127747.970000`**,
сырая сумма движка = **`127747.96`**. ⇒ **дефект в МОЁМ контроле**: он сравнивал сырую
сумму движка с целью, выведенной из **округлённых** значений. Дефект существовал с
момента написания контроля и к данным отношения не имеет.

### 🚫 Считать ли серию действительной — НЕ МОЁ РЕШЕНИЕ

Пре-регистрация гласила: «разошлись ⇒ серия **НЕДЕЙСТВИТЕЛЬНА**», **без допуска**.
Объявить сейчас, что копейка «не считается», значило бы решить это **после** того, как
я увидел, что `PF` попал в 96.5-й процентиль, — то есть ровно «чтение замера под
впечатлением», против которого и писалась запись `dd2ab6a`. Поэтому вердикт по
действительности серии **оставляю человеку** и не подменяю его своим.

**И это ни на что не влияет для решения**, см. раздел 2.

## 2. Статистика 3.1 — процентиль наблюдённого `PF 1.638`

| величина | значение |
|---|---|
| **процентиль наблюдённого `PF 1.638`** | **96.5** |
| распределение нуля: `p5` | `0.175` |
| медиана | `0.633` |
| `p95` | `1.483` |
| `min` / `max` | `0.056` / `3.187` |

**96.5 попадает в полосу 95–99**, а она объявлена в `dd2ab6a` дословно:

> **серия НЕ РАЗРЕШАЕТ.** `N = 200` — предел прибора. Решение **не принимается**,
> требуется серия большего `N`. 🚫 Трактовать «почти выше» **запрещено**.

⇒ **РЕШЕНИЕ НЕ ПРИНИМАЕТСЯ.** Ни «остаёмся в A», ни «переходим на B».
🚩 И отсюда следует важное: **вопрос о действительности серии решать не требуется**,
чтобы знать исход. Серия действительна ⇒ 96.5 ⇒ не разрешает. Серия недействительна ⇒
тем более не разрешает. Оба пути ведут к одному: **нужна серия большего `N`**.

### П-D1 ПОДТВЕРЖДЁН, и вывод обратен ожидаемому по смыслу

Прогноз: «медиана доли top-2 будет **≥ 100 %**». Получено **`224.9 %`** ⇒
**подтверждён**.

**Что это означает:** концентрация результата в двух сделках **НЕ специфична для наших
правил**. Случайный вход с той же механикой выхода (`2×ATR` с трейлингом) концентрирует
**сильнее** — `224.9 %` против наших `103.2 %`. То есть «тройка держится на двух
сделках» есть свойство **выборки из 18 сделок с этим выходом**, а не признак того, что
правила плохи.

## 4. Число убыточных прогонов — самостоятельная величина

| | значение |
|---|---|
| прогонов с **отрицательным** `PnL` | **167 из 200** |
| доля | **83.5 %** |

**Случайный вход убыточен в подавляющем большинстве прогонов.** По записи `dd2ab6a` эта
величина определяет **не переход, а с чего путь B начинается**, и при «большинство
убыточны» — **с расширения выборки**: новые правила ради большего числа сигналов.

🚫 Но применять эту ветку **сейчас нельзя**: она включается только **после** решения о
переходе, а решение не принято (раздел 2). Разделение двух величин, объявленное в
`dd2ab6a`, здесь и срабатывает — вторая величина **не может** отменить нерешённость
первой.

## 5. Что замер дал и чего не дал

**Дал:**
* распределение нуля впервые в истории проекта: медиана `PF 0.633`, `p95 1.483`;
* `83.5 %` случайных входов убыточны — то есть выход `2×ATR` сам по себе денег не
  делает, вопреки простому чтению «результат несёт механика выхода»;
* П-D1: концентрация в двух сделках — свойство выборки, не дефект правил.

**Не дал:**
* **решения по пути A/B** — `96.5` в полосе неразрешимости;
* действительности серии — вопрос оставлен человеку (раздел 1);
* значимости `PF 1.638` при большем `N` — потребуется новая серия, и её `N` обязан
  быть объявлен **до** запуска, как и здесь.
